Rôle de cette page

Configurer les accès aux agrégateurs de paiement (BJ PAY, FEDAPAY, KKIAPAY) utilisés pour les prestations payantes.

Actions disponibles
  • Éditer — modifie les clés et la configuration
  • Supprimer — supprime après confirmation
  • Activer / Désactiver — bascule la disponibilité du compte
Créer un compte

Cliquez sur Ajouter. Choisissez l'agrégateur, renseignez les clés API fournies par la plateforme, puis sélectionnez l'environnement (Test pour les essais, Production en exploitation).

Lier à une prestation

Dans Prestations, activez le toggle Prestation payante puis sélectionnez ce compte pour associer le paiement au service.
